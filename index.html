Rendering for a clinical workstation

July 2026 · MiNNOVAA ZEUS

OpenGL Rendering Engine for ZEUS

A new cinematic rendering engine for ZEUS, MiNNOVAA’s imaging workstation. It keeps an OpenGL 3.3 Core profile and ObjectTK abstractions for GPU resources, so the same path runs on the workstation GPUs already in the field.

Rays walk the volume with stochastic volumetric free-flight sampling. Hits respond with diffuse and GGX materials, lit by an HDR environment, then accumulate progressively. Transfer functions drive extinction; 3D volume textures feed the march; active-tile filtering skips settled tiles so interaction stays responsive.

Inspired by Mikhail Gorobets’ volume path-tracing work. Original LinkedIn post

GPU Direct Volume Rendering

One-pass ray marching of CT/MR 3D textures with MIP, DVR, and SSD compositing, up to eight masked layers, tricubic sampling, Blinn–Phong lighting, and clinical transfer-function presets. About 10× faster than the previous GDI renderer.

Digital Subtraction Angiography

Fo-Dicom to SimpleITK conversion and DSA for XA series. Roughly 2× faster than the prior Leadtools toolkit, which removed an ~$8,000 annual SDK cost.

Interactive 3D MPR

Oblique multiplanar reconstruction inside the live 3D volume: rotatable cross-sections, 2D/3D correlation, bounding-box crop, volume cut, and Camera3D navigation for trauma and surgical planning cases in the PACS viewer.
